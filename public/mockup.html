8 · Latest Batch LIVE

The newest features — real screenshots from production. Editable workout time, a "biggest week" record, a coach-editable video library, planned-vs-actual pace, a coach↔athlete reply loop, automatic morning-workout detection, and weekly-volume trends for runners & the whole team.

24 · Editable workout time LIVE

Coach sets the team workout's start time; it drives when the "coming today?" RSVP stops showing.

25 · "Biggest week" record LIVE

Peak weekly volume on the Momentum card, from full run history — celebrates a new record when this week tops it.

26 · Practice video library LIVE

Real Google-Drive thumbnails for published drills, a "coming soon" chip for placeholders. Coach-editable, no deploy.

27 · Video editor (coach) LIVE

Swap in live Drive file IDs, edit title/category/duration/description, add or remove drills — saved server-side.

28 · Planned-vs-actual pace LIVE

Green dashed planned pace overlaid on the actual per-km line, aligned by real split distances so intervals line up.

29 · Coach ↔ athlete reply LIVE

Coach replies to a workout's feedback; the athlete gets a push and sees "תשובת המאמן" with a "new" badge.
